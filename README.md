# Plaplago

Сторінки сайту Plaplago для GitHub Pages / Website pages for GitHub Pages.

- `index.html` — головна / home
- `privacy.html` — політика конфіденційності / privacy policy
- `terms.html` — умови використання / terms of use
- `delete-account.html` — видалення акаунта / account deletion

Мова перемикається кнопками EN / УКР; пряме посилання: `?lang=en` або `?lang=uk`.
